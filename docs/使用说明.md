# TIA Portal MCP Server —— 使用说明

给不熟悉编程的你看的。按顺序读完，就能用自然语言让 AI 帮你改博途里的 PLC 程序了。

---

## 一、这是什么东西

一个跑在你电脑上的服务，让 AI（像我）能直接操作你正在运行的**西门子 TIA Portal V21**：

- 读你的工程结构（有哪些程序块、用了哪些变量地址）
- **生成梯形图（LAD）并导入**，你在博途界面里立刻能看到
- 编译并把**完整的错误信息**带回来（不是"有个错"这种废话）

你不用写代码，也不用碰 XML。**直接用中文说需求就行。**

---

## 二、使用前必须知道的 3 件事

### 1. 博途必须开着，且已加载项目

这个服务是"附加"到已经运行的博途上，不是自己启动博途。所以：

- ❌ 博途关着 → 用不了
- ❌ 博途开着但没打开项目 → 用不了
- ✅ 博途开着 + 项目已加载 → 正常工作

**每次用之前确认一下博途开着。**

### 2. 改动会立刻出现在博途里，但在磁盘上是"未保存"

博途左下角或顶部标题栏会显示项目有未保存改动。

**我从不替你保存工程**（这是安全红线）。你看完满意了，自己按 `Ctrl+S`。

### 3. 第一次用会弹一个授权框

```
Openness 访问 (0033:000666)
'C:\path\to\PLCMCP\engine\bin\Debug' 中的应用程序 'TiaEngine.exe' 正试图访问 TIA Portal...
```

**点「全部确定」**（中间那个按钮），博途会永久记住这个授权，以后不再弹。

> 如果你看到两个博途实例都弹了，正常现象，都点一次即可。
> 建议关掉没加载项目的那个多余实例。

## 三、怎么连到 AI 客户端

在 MCP 客户端的配置文件里加一段：

```json
{
  "mcpServers": {
    "tia-portal": {
      "command": "E:\\PLCMCP\\mcp-server\\bin\\Debug\\net8.0\\TiaMcpServer.exe",
      "args": []
    }
  }
}
```

常用配置文件位置：
- Claude Desktop：`%APPDATA%\Claude\claude_desktop_config.json`
- 其他客户端找它的 `mcp.json` / `settings.json`

加完重启客户端，在工具列表里应该能看到 16 个以 `tia_` 开头的工具。

## 四、16 个工具分别干什么

| 工具 | 干的事 | 会不会改你的工程 |
|------|--------|-----------------|
| `tia_list_projects` | 列出博途开着哪些项目 | ❌ 只读 |
| `tia_browse_tree` | 看程序块树、变量表、已占用地址 | ❌ 只读 |
| `tia_compile_plc` | 编译并返回完整错误信息 | ⚠️ 只编译，不改代码 |
| `tia_import_scl` | 从 SCL 文本导入程序块 | ⚠️ 默认只预演 |
| `tia_import_lad_xml` | 导入梯形图（LAD） | ⚠️ 默认只预演 |
| `tia_plcsim_run` | PLCSIM 仿真相关 | ⚠️ 受限，见下 |
| `tia_save_project` | 显式保存当前工程 | ⚠️ 只在你说保存时执行 |
| `tia_ensure_tags` | 批量创建 PLC 变量 | ⚠️ 默认只预演 |
| `tia_ensure_instance_db` | 为 FB 创建实例 DB | ⚠️ 需先有 FB |
| `tia_export_block` | 导出程序块 XML | ❌ 只读 |
| `tia_ensure_watch_table` | 创建/打开监控表 | ⚠️ 会写入工程 |
| `tia_list_devices` | 列出当前设备 | ❌ 只读 |
| `tia_create_project` | 新建项目 | ⚠️ 会创建工程 |
| `tia_open_project` | 打开项目 | ⚠️ 会切换项目 |
| `tia_close_project` | 关闭项目 | ⚠️ 不会自动保存 |
| `tia_add_device` | 添加 PLC/HMI | ⚠️ 会改硬件组态 |

**关键安全设计**：所有会改工程的工具，**默认都是"预演模式"**——只告诉你"我要创建什么"，**不真的写**。你确认后我才真正执行。

## 五、你可以直接对 AI 说的话

### 看看我有什么

> "看看我现在这个博途工程里有什么程序块和变量"

### 生成梯形图

> "帮我在 OB1 里加一个电机启停回路：启动按钮 %I0.0、停止按钮 %I0.1、热保护 %I0.2，
> 输出接触器 %Q0.0 和运行指示 %Q0.1，要能自保持，热保护动作后锁定不许自动重启"

我会：先给你看要做什么 → 你点头 → 生成导入 → 编译 → 报告结果。

### 查错误

> "编译一下，把所有错误列出来"

会返回**每一行**的错误位置和完整描述（不截断），因为这些信息是改代码的唯一依据。

### 常规语句

| 你说 | 效果 |
|------|------|
| "列出所有块" | 只读查看 |
| "看看 %I 用了哪些地址" | 只读查看，避免地址冲突 |
| "加个 3 秒定时器" | 生成梯形图 |
| "把刚才那个改一下" | 修改并重新编译 |

## 六、安全边界（已经写死在代码里）

| 规则 | 怎么保证的 |
|------|-----------|
| **只碰你指定的那个项目** | 配置文件 `tia-scope.txt` 白名单，范围外直接拒绝 |
| **删除只在命令行** | `delete_blocks` / `delete_tags` 不暴露为 MCP 工具，删东西仍由你在博途里做 |
| **保存必须明确说** | 只有 `tia_save_project` 会保存；其他工具不会隐式保存，`Ctrl+S` 仍可自己按 |
| **不改硬件组态** | 代码里没有增删模块/改 IP 的调用 |
| **不破坏 OB1 原逻辑** | 生成的梯形图只**追加**新程序段，已有的段原样保留 |
| **不猜着改代码** | 编译失败时只依据博途返回的原始错误改，不瞎猜 |
| **写入默认预演** | 写操作默认 `dry_run=true`，要真执行你必须明说 |

> 想让 AI 碰别的项目？编辑 `C:\path\to\PLCMCP\tia-scope.txt` 加一行目录，立刻生效。

## 七、变量名建议用中文

博途完全支持中文变量名，实测生成和编译都没问题：

```
启动按钮  %I0.0      停止按钮  %I0.1      热保护    %I0.2
接触器    %Q0.0      运行指示  %Q0.1
```

在梯形图里看到的是中文，比 `Start_Button` 好懂得多。你说"变量名叫中文"我就会照做。

## 八、自己动手跑（可选）

想不用 AI，自己跑也行：

```powershell
# 看看工程里有什么（只读）
C:\path\to\PLCMCP\engine\bin\Debug\TiaEngine.exe --mode browse_tree

# 编译看错误
C:\path\to\PLCMCP\engine\bin\Debug\TiaEngine.exe --mode compile_plc

# 一键生成梯形图（导出→生成→建变量→导入→编译→检查）
powershell -File C:\path\to\PLCMCP\ladsim\lad-pipeline.ps1
```

所有命令返回的都是一段 JSON：
```json
{"ok":true,"mode":"browse_tree","dryRun":false,"result":{...},"error":null}
```
- `ok`：成功还是失败
- `dryRun`：`true` 表示只是预演，没真改
- `error`：失败时这里有 `code`（错误代号）和 `message`（中文说明）

## 九、遇到问题怎么办

| 现象 | 原因和做法 |
|------|-----------|
| 提示 `NO_TIA_INSTANCE` | 博途没开，或没加载项目 |
| 弹 Openness 授权框 | 点「**全部确定**」，一次就够 |
| 提示 `PROJECT_NOT_ALLOWED` | 项目不在白名单，改 `tia-scope.txt` |
| 提示 `EXPORT_INCONSISTENT_BLOCK` | 博途里刚改完没保存，或块有编译错误。先保存或先修错误 |
| 导入报"程序代码与架构不符" | 生成的 XML 格式不对，把**完整报错**发我，我照着修 |
| 变量地址冲突 | 先 `browse_tree` 看已占用地址，换个空的 |
| PLCSIM 相关操作不支持 | 见下一节 |

## 十、PLCSIM 仿真的限制

博途自带的 **PLCSIM V21 标准版是个独立的桌面程序，没有对外接口**，所以：

- ❌ AI 不能替你启动 PLCSIM
- ❌ AI 不能直接读写仿真里的变量
- ✅ 你手动启动 → 博途下载 → 用**监控表**看变量

**手动流程（约 2 分钟）**：

1. 运行 `D:\Program Files\Siemens\Automation\PLCSIM_V21\S7PLCSIMV21.exe`
2. 博途里右键 `PLC_1` → **下载到设备** → 选 PLCSIM 虚拟接口 → 搜索 → 加载
3. 加一张**监控表**，加入 `%I0.0 启动按钮`、`%Q0.0 接触器`、`%Q0.1 运行指示`
4. 仿真启动后拨开关验证：
   - 拨 `%I0.0` → 接触器吸合，指示灯亮
   - 拨 `%I0.1` → 断开
   - 断 `%I0.2` → 锁定，即使松开也不自动重启

> 如果以后想要 AI 直接读写仿真变量，需要装 **PLCSIM Advanced**（它提供 REST API + S7 协议）。
